# AIMODrive

App Android moderna sviluppata in Flutter, progettata come file manager cloud nativo e modulare.

## Obiettivo
Creare un file manager cloud multipiattaforma con supporto a più provider (Google Drive, OneDrive, Dropbox, WebDAV), architettura estensibile tramite plugin e interfaccia Material 3.

## Architettura
- **Framework:** Flutter
- **UI:** Material 3
- **State Management:** Riverpod
- **Routing:** GoRouter
- **Pattern:** MVVM

## Release 0.1 - Starter
Include la struttura base, il routing, il tema chiaro/scuro e l'impalcatura per i provider cloud.
